# 📊 Excel Data Analytics Projects

Welcome to my Excel Data Analytics portfolio! 👋

This repository showcases a collection of hands-on Microsoft Excel projects focused on solving real-world business problems through data cleaning, analysis, visualization, and dashboard creation.

Each project follows a complete analytics workflow:

**Raw Data → Data Cleaning → Pivot Analysis → Business Insights → Interactive Dashboard**

---

# 🌱 My Learning Journey

These are the first complete data analytics projects I built on my own.

This journey was both exciting and challenging. One of the biggest challenges was finding suitable datasets, downloading them, cleaning messy data, and transforming it into something meaningful for analysis.

Writing Excel formulas independently and understanding business logic took time, but every project helped me improve my problem-solving skills and confidence.

Throughout this learning process, I used AI tools such as **ChatGPT** as learning companions to understand concepts, improve my dashboards, and learn better approaches. Every dashboard, analysis, and improvement helped me strengthen my Excel and analytical thinking.

These projects represent the beginning of my journey toward becoming a Data Analyst, and I look forward to continuously improving them as I learn new skills.
